# SoloBizKit — Website source package

A responsive, static English-language small-business tools website.

## Included
- Responsive homepage and mobile navigation
- 8 working calculators: profit margin, markup, break-even, freelance hourly rate, invoice total, sales tax, project pricing, loan payment
- 12 original starter educational guides
- About, Contact, Privacy and Terms starter pages
- SEO basics: page titles/descriptions, canonical placeholders, sitemap.xml, robots.txt
- ads.txt placeholder and clearly marked ad placement placeholder

## Preview locally
1. Unzip this folder.
2. Open `index.html` in a modern browser.
3. Test each calculator from the homepage.

No build step or package installation is required.

## Before publishing
1. Replace every `YOUR-DOMAIN.example` with your real domain in canonical URLs, sitemap.xml and robots.txt.
2. Replace `hello@YOUR-DOMAIN.example` with an email address you control.
3. Review Privacy Policy and Terms for your actual business, jurisdiction, analytics and advertising setup.
4. Do not add an AdSense publisher line to ads.txt until Google provides your exact line.
5. Submit the site for AdSense only after it has original, useful content, working navigation, required policy pages and meets current Google policies. Approval is not guaranteed.
6. Configure your domain and HTTPS with your hosting provider.

## Deploy as a static site
Upload the contents of this folder (not the outer folder itself) to a static host such as Cloudflare Pages. Use the root directory as the project root. No build command is needed; the output directory is `/`.

## Important
The calculators provide estimates for general educational and planning purposes. Tax, legal, lending and accounting rules vary by location. This website is a starter package, not a guarantee of advertising approval or income.
